SCROLL                   User Commands                   SCROLL

NAME
    scroll - show a file with fast/slow scrolling

SYNOPSIS
    scroll [file]

DESCRIPTION
    scroll shows a file one page at a time. It starts by showing the
    first page. The user can page forward or start scrolling slowly.

    If no file is given, it reads from standard input.

KEYS
    space   Show next page and stop scrolling.
    enter   Start or stop scrolling.
    f       Scroll faster.
    s       Scroll slower.
    q       Quit.
